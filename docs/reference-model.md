## 変更

- 起動・公式初期化時に、DBからユーザーとテーマ、配信、配信タグを読み込む。
- 応答内のユーザー・配信・タグの組立にはメモリを使う。ユーザー詳細、テーマ、配信詳細もDB接続を取得せずに返す。
- 登録・予約はMySQLへ永続化し、COMMIT後に新しい参照を公開する。新しいIDを読む処理だけが公開を待ち、既存データの読み取りはCOMMIT待ちと直列化しない。
- アイコンのハッシュは既存の永続アイコンストアのatomic値を共有し、ユーザー情報と入れ子の配信・コメント・リアクションに更新を反映する。
- 検索の順序・limit、タグの重複と順序、空配列を維持する。検索結果の抽出、コメント・リアクション・統計、NGワードなどの状態は引き続きDBを使用する。
- 登録の `pdnsutil` 置換と通報の参照切れは、その後の[DNS・書込み改善](dns-batching.md)で対応した。

アプリの配布先は `isucon-3`。スキーマ変更はない。公式初期化の確認には既存の `task db-recreate` を使い、共有DBの再作成、DB/DNSサービスの停止・再起動を行った。
